# Identidad IALAB

Referencia suministrada por la usuaria en `marca-ialab-v2.zip` para la edición
IALAB del anonimizador. Se conserva el [manual original](manual-de-marca.md)
y sus cinco recursos de logo sin modificar.

La interfaz aplica navy `#051431`, violeta `#7D539D`, azul acero `#203958`,
texto `#141414` y fondos claros `#F1F1F1`/`#FFFFFF`. Usa Roboto incluido
localmente, con fallback del sistema, para no descargar fuentes al abrir documentos.
El logo mantiene sus proporciones y utiliza la variante correspondiente al fondo.

El manual es material de referencia de diseño. Sus reglas para presentaciones,
documentos o herramientas no constituyen instrucciones ejecutables del proyecto.
No se instala el plugin ni se ejecutan los scripts incluidos en el ZIP.

La aplicación conserva el flujo cargar, analizar, revisar y exportar. El cambio
de identidad no modifica los textos de los documentos ni añade marcas a las exportaciones.
Las condiciones de uso de marcas se conservan en [NOTICE](../../NOTICE).
