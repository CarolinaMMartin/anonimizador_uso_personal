PRIVACY AND OFFLINE OPERATION
The frontend uses system fonts, without web font or CDN downloads.
Presidio's EmailRecognizer is disabled; email detection uses local regex.
tldextract uses its local snapshot; analysis requires no network.
Sessions are held in process memory; no SQLite session database is created
automatically by the normal application workflow.
The release excludes user documents, sessions, equivalence CSVs and logs.
Exported equivalence CSVs contain original personal values.
